# PSF-IAminy — Regra de versão única, etapa única e posição única

O PSF-IAminy é um só.

Não existe versão nova por cima de versão antiga, não existe etapa concorrente, não existe motor substituto escondido e não existe sobreposição de verdades.

## Regra central

```text
mesma versão
mesma etapa de continuidade
mesma posição
mesmo corpo do projeto
```

Quando algo melhora, a melhoria entra no mesmo corpo do PSF-IAminy. Os nomes históricos `ETAPA_*.md` e os temas de Português são apenas localizadores; todo o conhecimento permanece na mesma linha única. O que estava fraco é corrigido, reorganizado, riscado no plano ou documentado como limite. Nada é duplicado para fingir avanço.

## Permitido

- Corrigir código existente.
- Reorganizar sem mutilar.
- Adicionar regra sagrada coerente.
- Atualizar README, plano e relatório único.
- Usar dependência externa apenas para comparação e otimização.
- Riscar no plano o que foi feito.
- Executar tarefas por urgência ou prioridade, mesmo fora da ordem numérica.

## Proibido

- Criar “v1”, “v2”, “nova edição” ou “edição final” interna.
- Criar outro projeto para substituir este sem integração.
- Manter duas respostas oficiais para a mesma coisa.
- Criar plano paralelo.
- Criar vários relatórios soltos.
- Apagar histórico do plano para parecer limpo.
- Antecipar conhecimento que não foi construído pelo PSF.

## Regra curta

> PSF-IAminy cresce por integração, não por versões.
